## 拼音 / 国际音标输入模式（任意音节）

在设计台「朗读文本」旁（或音色实验室「试听」旁）切换输入模式，即可不写汉字、直接用**拼音**或**国际音标（IPA）**控制发音，合成**任意普通话音节组合**——生造词、不存在的“字”、非常规声调搭配、方言味音节都可以。

### 拼音模式

- **格式**：音节 + 声调数字（1-4，轻声 5；省略则按最常见读音），如 `ni3 hao3 shi4jie4`；也支持声调符号 `nǐ hǎo`；ü 写 `v`（`lv3`、`nv3`）；`xi'an` 用撇号分词；儿化写 `huar1`；标点 `，。、` 可用。
- **切分**：音节之间加空格最稳；不加空格时按最长匹配切分（`xian`→先，`xi'an`→西安）。无法识别的音节/声调会报错并提示可用声调（如佛只有 `fo2`）。

### 国际音标（IPA）模式 + 软键盘

选中「国际音标（IPA）」后，文本框下方出现**软键盘**，分组提供普通话音系的全套 IPA 符号（点击在光标处插入，支持退格）：

- **声母**：不送气/送气对立成对排列——`p`(=拼音b) `pʰ`(=p)、`t`(=d) `tʰ`(=t)、`k`(=g) `kʰ`(=k)、`ts`(=z) `tsʰ`(=c)、`tʂ`(=zh) `tʂʰ`(=ch)、`tɕ`(=j) `tɕʰ`(=q)；擦音 `f`(f) `s`(s) `ʂ`(sh) `ɕ`(x) `x`(h) `ʐ`/`ɻ`(r)，鼻/边音 `m n l`。
- **元音**：`a o ə(=e，写 ɤ 亦可) ɛ i u y(=ü) ɚ(=er)`；舌尖元音 `ɿ`(z/c/s 组的 i) `ʅ`(zh/ch/sh/r 组的 i)；介音 `j w ɥ`。
- **韵母**：复合/鼻韵母整体插入（`au`=ao、`ən`=en、`aŋ`=ang、`əŋ`=eng、`ja`=ia、`jɛ`=ie、`jau`=iao、`jɛn`=ian、`juŋ`=iong、`wa`=ua、`wo`=uo、`wei`=ui、`wən`=un、`ɥɛ`=üe、`yn`=ün 等），键下标注对应拼音。
- **声调**：Chao 调符 `˥`(一) `˧˥`(二) `˨˩˦`(三) `˥˩`(四)、上标 `¹²³⁴⁵`、普通数字 `1-5`（轻声 5，不标取默认）。
- **记音示例**：`tʂuŋ¹kwo³`=中国；`pʰan˧˥`=盘；`tsɿ¹sz̩³`=自私；送气不可省略（`pan`=班、`pʰan`=盘）。
- **容错**：`ɤ/ə`、`ɪ/i`、`ɑ/a`、`ʊ/u`、`ʈ/t` 等近似变体自动归一；音系外符号（`ð`、`ʘ`、挤喉音等）报错提示。

### 通用音标模式（全语言 · espeak-ng）

要发**普通话音系之外**的声音（法语鼻化元音、小舌颤音、咽擦音、喷音等），把输入模式切到「通用音标（全语言·espeak）」：走 espeak-ng 共振峰合成器，软键盘自动切换成**完整 IPA 图表**（塞音/塞擦音/擦音/鼻近边音/单元音/组合/超音段与声调），**未通过验证的符号按键自动灰化**。

- **首次启用**：① `winget install eSpeak-NG.eSpeak-NG`（或从 [espeak-ng Releases](https://github.com/espeak-ng/espeak-ng/releases) 下载 `espeak-ng.msi` 安装）；② 项目目录运行 `.venv/Scripts/python.exe verify_espeak_map.py` 生成 `assets/espeak_ipa_map.json`（用真实 espeak-ng 逐条验证 IPA→espeak 代码映射，只写入通过验证的条目）。本机已完成：79 个符号 + 长音 + 五声调。
- **实测可用**：法语 `b ɔ̃ ʒ u ʁ`、四声 `m a ˥ m a ˧˥ m a ˨˩˦ m a ˥˩`、送气+喷音 `pʰ i ˧˥ tʼ o ˥˩`、长音 `b a ː`。声调/长音会自动附着到前一个元音；系统按输入内容自动选择覆盖最全的声部（fr/cmn/en-gb/…），预览行可见选中声部与 espeak 音素串。
- **诚实的边界**：音质是机械合成音（共振峰合成，非神经网络的自然声）；仅语速/音高/音量三个参数生效，音色选择与 19 个声学调节不适用；重音标记（ˈ ˌ）与停顿（.）经 espeak 实测无效，已剔除；支持哪些符号以键盘按键是否可用为准（未验证的约 28 个符号——卷舌音系列、部分中元音等——按键灰化并报错）。
- **原理**：espeak-ng 的 `[[...]]` 音素输入使用其自有助记代码（如 `tS`=tʃ、`@`=ə、`A~`=ɑ̃、`p_h`=pʰ），不是 IPA；映射表由验证脚本从真实二进制生成（候选拼写 round-trip + `-X` 自省 + 差分验证三管齐下），运行时只加载已验证条目，未验证符号明确报错。

### 通用说明

- **实时预览**：输入时显示“将朗读：你好（2 音节）”（IPA 模式还显示中间拼音层）——即实际送入模型的同音汉字串，发音以此为准。
- **原理**：ChatTTS 的输入层是 BERT 中文字符 token（词表 21128，没有拼音/音素 token），发音知识在模型权重里。本项目把拼音/IPA 音节替换成同音汉字（`assets/pinyin_syllables.json`，1349 个带调音节，由 `build_pinyin_map.py` 用 pypinyin 反查生成；候选字限定在模型词表内，优先“主读音匹配”与 ChatTTS 官方 homophones 验证字），并跳过 refine_text 改写（否则模型可能把生造音节串改写成读音相近的正常词语），让模型逐字按音节发音。IPA→拼音的转换表内置于 `voice_design_server.py`（声母/韵母/特殊音节 + 折叠归一）。
- **限制（诚实说明）**：只能发普通话音系内的音，弹舌音、唇齿颤音等非普通话声音无法生成；连续变调（一/不变调、上上相连）由模型自动处理，无法完全禁止；儿化用「X儿」两字近似；不标声调时的默认声调按词组词频+常用功能词表选取，个别音节（如 `dian` 默认 `diàn` 电）可能与预期不同，看“将朗读”预览补声调即可。

## 音色实验室（`/lab`）

启动服务后打开 `http://127.0.0.1:8765/lab`（或从设计台首页顶部链接进入）。两个页面共享同一批音色：

- **查看图形**：点选左侧音色库中的任意音色，右侧以折线图显示其数据。嵌入向量音色显示 768 维曲线（带最小/最大/均值/L2 范数统计）；从 WAV 提取的音色显示 4 层音频提示 token（只读）。
- **手动编辑**（仅嵌入向量音色）：在图上按住拖动直接改写曲线；用「序号/数值」精修单点；批量工具支持缩放、偏移、平滑、随机抖动、区间归零，并可撤销/重做/还原；「数值表」可逐格输入全部 768 个数值。编辑后点「另存为新音色」保存（原音色不受影响）。
- **导入音色串**：粘贴网上分享的 ChatTTS 音色串（嵌入串或音频提示串）即可入库、编辑、试听。
- **从 WAV 提取**：上传 5~12 秒干净人声 WAV（16bit PCM 最佳），填写音频里说的参考文本后点「提取并保存」。程序自动静音修剪、重采样到 24kHz，用 ChatTTS 的 `sample_audio_speaker` 生成音频提示并保存。提取音色和编辑音色都能直接试听，也会出现在设计台的音色下拉列表中。
- **管理**：自定义音色可改名、删除、导出为文本串；固定音色只读但可导出。数据保存在 `data/custom_speakers.json`。

技术说明：音色串是 float16/uint16 二进制经 LZMA 压缩后再 base16384 编码的 Unicode 字符串，页面上显示为“汉字乱码”属正常现象，不要手工修改其中的字符；本项目的编码/解码实现与 ChatTTS 0.2.5 官方实现逐字节一致（已验证往返一致）。提取音色（音频提示）合成极短文本（约 10 字以内）时 ChatTTS 可能生成不出音频，页面会提示换更长的文本。

## Windows 启动

1. 安装 Python 3.11，并确保命令行可通过 `py -3.11` 找到它。
2. 安装 FFmpeg，并把 `ffmpeg.exe` 所在目录加入 PATH。
3. 确认项目 `.venv` 已用 Python 3.11 创建，并已安装 `requirements.txt` 中的依赖；之后双击 `start.bat`。启动脚本会检查 Python 版本、ChatTTS 依赖、FFmpeg 和已有模型缓存，不会自动安装缺失依赖。
4. 页面会在浏览器打开，地址为 `http://127.0.0.1:8765`。保留命令窗口运行服务，按 Ctrl+C 停止。

启动脚本默认使用 `https://huggingface.co` 下载模型；如果所在网络需要镜像，可在同一个命令窗口先执行 `set HF_ENDPOINT=https://你的镜像地址`，再运行 `start.bat`。若缓存不完整，脚本会提示缓存目录；确认服务已停止后手动删除该目录，再重新启动。

如果启动失败，窗口会保留英文错误信息，诊断日志写入同目录的 `start.log`。若 `.venv` 的 Python 版本不对，请用 Python 3.11 重建虚拟环境，并安装 `requirements.txt`。

## macOS 启动

需要 Python 3.11 和 FFmpeg。可通过 Homebrew 安装后，在项目目录执行：

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python voice_design_server.py
```

再打开 `http://127.0.0.1:8765`。Apple 芯片会尝试使用 MPS；ChatTTS 部分模块仍可能使用 CPU，推理速度和内存占用取决于设备。

## 使用

- 选择 60 个普通话固定音色之一，输入文本（中文，或切换拼音 / 国际音标模式输入音节）后点击 **生成并试听**。
- 可继续调整音高、音高起伏、语速、音量、明亮度、温暖度、厚度、鼻音、声带张力、清晰度、存在感、空气感、齿音、气声、粗糙度、平滑度、压缩、距离感和房间感。
- 每次生成都会保存 WAV 到 `outputs/`，并新增到浏览器历史记录。
- 历史条目可以收藏、删除、设为 A/B，或恢复成下一轮参数起点。预设保存参数组合，不包含音频。
- 首次模型下载期间按钮会显示“生成中…”，状态栏会显示已等待时间；若下载失败，状态栏会显示后端错误，再次点击按钮即可重试。

历史记录和预设保存在浏览器本地。模型权重及固定说话人嵌入保存在项目目录；备份项目时可一并保留 `models/` 和 `data/`。
